# AGENTS.md

A one-page site used to test agent skills. Work goes to an integration branch; releases go to `integration-main`.

## Git workflow

- Base branch: integration-dev
- Branch names: feature/, fix/, docs/, chore/
- Commits: Conventional Commits
- Checks: ./check.sh
- Changelog: CHANGELOG.md, under [Unreleased]
- Update method: rebase
- task-flow mode: safe
- Tracker: GitHub issues, `Closes #N` in the pull request body
