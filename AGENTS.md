# AGENTS.md

A small Python command-line tool used to test agent skills. Dependencies are managed with Poetry.

## Git workflow

- Base branch: python-poetry
- Branch names: feature/, fix/, chore/
- Commits: Conventional Commits
- Checks: poetry run pytest -q
- Changelog: CHANGELOG.md, under [Unreleased]
- Update method: rebase
- task-flow mode: safe
