# AGENTS.md

A small notes service used to test agent skills. Decisions are recorded in `docs/adr/` in MADR format.

## Git workflow

- Base branch: adr
- Branch names: `feature/`, `fix/`, `docs/` plus 2 to 4 lowercase words
- Commits: Conventional Commits
- Checks: ./check.sh
- Changelog: none
- Update method: rebase
- task-flow mode: safe
