# Record architecture decisions

Status: Accepted
Date: 2026-03-02

## Context and Problem Statement

Decisions about the notes service live in chat threads and get lost.

## Considered Options

* Markdown records in the repository (MADR)
* A wiki page

## Decision Outcome

Chosen option: "Markdown records in the repository (MADR)", because they are reviewed with the code and versioned with it.

### Consequences

* Good, because every decision has a pull request and a date.
* Bad, because someone has to write them.
